# Contributing to Biblionx

Thank you for helping improve Spanish (Dominican Republic) to Dominican Sign Language (LSRD) translation.

## Workflow

1. Fork the repository or create a branch from `main` (for example `feat/short-description` or `fix/short-description`).
2. Make focused changes and commit them with clear messages.
3. Open a pull request against `main` of the same repository.
4. All CI checks must pass before a pull request can be merged.
5. A maintainer reviews and merges the pull request.

## Language conventions

- Code, comments, commit messages and documentation are written in **English**.
- Spanish is used only for dictionary data (entries, glosses, Spanish linguistic data) and audience-facing deliverables.

## Rules

- Do not commit personal data, API keys, tokens or other secrets. These repositories are public.
- Never open pull requests against the original VLibras repositories. Biblionx is an independent project and does not push changes upstream.
- Report security issues privately, as described in [SECURITY.md](SECURITY.md).

## Conduct

By participating you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
