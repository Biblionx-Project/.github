# Security Policy

## Supported versions

| Repository | Supported |
| :--- | :--- |
| `biblionx-lsrd-translator` | The latest release only |
| Reference repositories (`biblionx-libraske-processor`, `biblionx-player-webjs`, `biblionx-translator-api`, `biblionx-translator-text-core`, `biblionx-web-browsers`) | Best-effort fixes. They are archived-style architecture references and not active dependencies of the product. |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub Security Advisories:

1. Open the affected repository on GitHub.
2. Go to the **Security** tab.
3. Click **Report a vulnerability** and describe the issue.

Include the affected version or commit, steps to reproduce, and the impact you expect. Do not include personal data or real credentials in the report.

Maintainers will acknowledge the report, work on a fix, and coordinate disclosure through the advisory. Reports against the reference repositories are handled on a best-effort basis.
